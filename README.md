# Documentación del Curso de CSS | Ejemplos Prácticos

Demostración interactiva y laboratorio de maquetación web para el curso de **Programación Web - CSS3, Flexbox y CSS Grid Layout**.

## 📌 Contenido del Curso

1. **Módulo 1: Maquetación Tradicional (Floats y HTML Semántico)**
   - Estructura semántica con etiquetas HTML5 (`header`, `nav`, `section`, `article`, `aside`, `footer`).
   - Uso de `float: left` con anchos dinámicos (`calc()`).
   - Técnica de limpieza de flujo con `.clearfix { clear: both; }`.

2. **Módulo 2: Flexbox (Layout Flexible y Modular)**
   - Propiedades de contenedor: `display: flex`, `flex-flow: row wrap`.
   - Dimensionamiento de elementos hijos: `flex-grow`, `flex-basis`.
   - Reordenamiento visual independiente con `order`.

3. **Módulo 3: CSS Grid Layout (Diseños Bidimensionales en Rejilla)**
   - Definición de plantilla en filas y columnas (`grid-template-columns`, `grid-template-rows`).
   - Asignación de áreas y expansión de celdas (`grid-column`, `grid-area`).
   - Alineación y distribución con `justify-content: stretch`.

4. **Matriz Comparativa de Métodos de Maquetación**
   - Comparación directa entre Floats, Flexbox y Grid Layout.

## 🚀 Tecnologías empleadas

- **HTML5 Semántico**
- **CSS3 Puro** (Variables CSS, Flexbox, Grid, diseño responsivo, fuentes tipográficas Google Fonts)
- **JavaScript Vanilla** (Copia rápida de snippets de código y scrollspy)
