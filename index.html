Módulo 2

Clase Flexbox: Layouts Modulares y Flexibles

Flexbox (Flexible Box Layout Module) permite diseñar estructuras unidimensionales dinámicas, distribuyendo el espacio entre elementos y alineándolos eficazmente.

Dirección y Envoltura

Propiedades display: flex, flex-direction: row y flex-wrap: wrap combinadas en flex-flow: row wrap.

Flex Grow & Basis

Control de proporciones mediante flex-grow y tamaño inicial relativo mediante flex-basis: 50%.

Propiedad Order

Reordenamiento visual independientemente del orden de los elementos en el marcado HTML mediante order: 1..4.

📄 Reglas CSS de Flexbox empleadas 
/* Contenedor Flex */
.flex-container {
    display: flex;
    border: 1px solid rgb(70, 69, 69);
    background: #ccc;
    padding: 20px;
    flex-flow: row wrap;
    width: 80%;
    margin: 0 auto;
    justify-content: flex-start;
    align-content: center;
}

/* Hijos flexibles con propiedades individuales */
.c1 { background-color: lightblue;  order: 1; flex-grow: 5; flex-basis: 50%; }
.c2 { background-color: lightcoral; order: 2; flex-grow: 2; }
.c3 { background-color: lightgreen; order: 3; flex-grow: 3; }
.c4 { background-color: lightgoldenrodyellow; order: 4; flex-grow: 4; }
Módulo 3

Clase Grid: Diseños Bidimensionales en Rejilla

CSS Grid Layout es el sistema de maquetación bidimensional más potente de CSS, permitiendo ubicar elementos en filas y columnas simultáneamente con máxima precisión.

Grid Columns & Rows

Definición de plantilla con grid-template-columns: auto auto y alturas grid-template-rows: 100px auto.

Grid Area & Spanning

Posicionamiento explicito mediante grid-column: 1/4, expansiones span 3 y la regla atajo grid-area.

Alineación Stretch

Distribución de ítems aprovechando el ancho disponible con justify-content: stretch.

📄 Reglas CSS de Rejilla empleadas 
/* Contenedor Grid Principal */
.grid-layout {
    width: 80%;
    margin: 0 auto;
    background-color: lightgreen;
    padding: 20px;
    border: 1px solid black;
    display: grid;
    grid-template-columns: auto auto;
    grid-template-rows: 100px auto;
    justify-content: stretch;
}

/* Áreas y columnas asignadas a las cajas */
.caja1 { grid-column: 1/4; background-color: lightblue; grid-area: 1 / 1 / 3 / 4; }
.caja2 { grid-column: 1/3; }
.caja3 { grid-column: 1/4; }
.caja4 { grid-column: 3 / span 3; }
Resumen

Matriz Comparativa de Métodos de Maquetación

Compara fácilmente cuándo utilizar cada técnica aprendida en las lecciones del curso.

Técnica Dimensiones Casos de Uso Ideales Ventaja Principal
Floats & Posicionamiento 1D (Horizontal básico) Sitios legacy, envolvimiento de texto alrededor de imágenes, columnas sencillas. Soporte total en navegadores antiguos sin requerir sintaxis moderna.
Flexbox 1D (Fila o Columna) Menús de navegación, barras de herramientas, centrado de elementos, tarjetas dinámicas. Excelente distribución de espacio libre y alineación vertical/horizontal rápida.
CSS Grid Layout 2D (Filas y Columnas) Layouts de páginas completas, galerías complejas, paneles de control (dashboards). Control total sobre filas y columnas simultáneamente sin depender de anidaduras de contenedores.
